# Mein Mathetrainer – Android TV / الهاتف

هذه النسخة المدمجة المحدّثة من التطبيق.

## التعديلات في هذه النسخة
- إزالة شخصية البومة بالكامل.
- إضافة صورتين داخل التطبيق: مالك مع شخصية الفأر الكرتونية، ومحمد مع الشخصية نفسها.
- التبديل بالتناوب بين صورة مالك وصورة محمد أثناء الانتقال بين الأسئلة.
- تنظيم مكعبات الآحاد في **خمسة مكعبات بكل سطر** (5 + الباقي)، بدلاً من ظهور ستة مكعبات في السطر.
- الصور محفوظة محلياً داخل التطبيق، لذلك لا تحتاج إلى اتصال بالإنترنت لعرضها.

## إنشاء APK عبر GitHub Actions
1. فك ضغط هذا الملف، ثم افتح مجلد `MeinMathetrainer-AndroidTV`.
2. انسخ محتوياته إلى مجلد المستودع المحلي نفسه، مع الموافقة على استبدال الملفات عند الطلب.
3. افتح GitHub Desktop، ثم اكتب وصفاً في Summary مثل: `Add Arabic and German voice and character reactions`.
4. اضغط **Commit to main** ثم **Push origin**.
5. افتح المستودع في GitHub ثم تبويب **Actions**.
6. افتح أحدث عملية باسم **Build Android TV APK** وانتظر ظهور علامة النجاح الخضراء.
7. من قسم **Artifacts** حمّل `Taallam-ma-Malik-AndroidTV-v2.0-APK`، ثم فك الضغط لتحصل على `app-debug.apk`.

## الإصدار 2.3 – حول التطبيق والبحث عن تحديث

- رقم الإصدار في Android هو 2.3 (versionCode 12).
- أضيفت نافذة «حول التطبيق / Über die App» إلى الشاشة الرئيسية.
- زر البحث يتصل بواجهة GitHub Releases للمستودع `anaskasham/MeinMathetrainer` ويقارن رقم أحدث إصدار منشور مع الإصدار المثبّت.
- إذا وُجد إصدار أحدث ومرفق معه ملف APK، يظهر زر تنزيل التحديث ويفتح رابط التنزيل.
- يجب نشر ملف APK داخل GitHub Release بعنوان tag مثل `v2.3` حتى يعثر عليه التطبيق. ملفات Actions Artifacts وحدها لا تظهر في قائمة Releases.
- يتطلب البحث اتصال الإنترنت، وقد أضيف إذن INTERNET إلى التطبيق.

**تنبيه مهم للتجربة:** APK الإصدار 2.3 المبني عبر GitHub Actions قد يحمل مفتاح توقيع مختلفاً عن APK الإصدار 2.1 الذي ثُبّت سابقاً. إذا رفض Android تثبيته كتحديث بسبب اختلاف التوقيع، لا تحذف التطبيق قبل التأكد من حفظ التقدم؛ سنحتاج إلى توحيد مفتاح التوقيع أولاً أو إزالة النسخة القديمة بعد قبول فقدان بياناتها.

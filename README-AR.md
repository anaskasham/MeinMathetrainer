# تطبيق نحسب حتى 100 – Android TV / الهاتف والتابلت

هذه نسخة دمج 1.3: تعتمد واجهة HTML التي رفعها المستخدم، داخل تطبيق Android TV WebView.

## ما تم دمجه وتحسينه
- واجهة وتمارين النسخة الجديدة (10 مستويات، العربية والألمانية، الشخصية الكرتونية، المكعبات، المساعدة، المكافآت).
- 10 إجابات صحيحة مطلوبة لإكمال المستوى وفتح المستوى التالي. الإجابة الخاطئة لا تزيد التقدم.
- أصوات نجاح/خطأ أصلية من Android، مع نطق Text-to-Speech للألمانية والعربية إذا كانت بيانات الصوت متاحة على الجهاز.
- ربط أسهم الريموت وزر OK/Enter وزر الرجوع بمعالجة صريحة داخل الصفحة.
- وضع ملء الشاشة، منع إطفاء الشاشة أثناء التدريب، وحفظ التقدم محلياً.
- أيقونة التطبيق وإعداد Android TV.

## بناء APK عبر GitHub
1. استبدل محتويات مستودعك بهذه الملفات (لا تحذف مجلد `.git` المحلي).
2. في GitHub Desktop اكتب رسالة commit مثل `Merge new math trainer UI v1.3` ثم Commit to main ثم Push origin.
3. افتح المستودع على GitHub ثم Actions. انتظر اكتمال `Build Android TV APK` بعلامة خضراء.
4. افتح عملية البناء الأخيرة، ثم نزّل Artifact باسم `Rechnen-bis-100-AndroidTV-v1.3-APK`.
5. فك ضغط ZIP لتحصل على `app-debug.apk`.

## التثبيت والاختبار
انقل APK إلى USB وثبته على Xiaomi TV Box. اسمح بالتثبيت من هذا المصدر عند الطلب. اختبر: الدخول للمستوى، الأسهم الأربعة، OK، الرجوع، صوت الإجابة الصحيحة والخاطئة، والنطق.

ملاحظة: نطق العربية يعتمد على توفر صوت عربي في محرك Text-to-Speech المثبت على جهاز Android TV. أصوات النجاح والخطأ لا تعتمد على ذلك.
